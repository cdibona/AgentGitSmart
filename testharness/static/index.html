Quick start

  1. Add a local repo: bash benchmark/setup_repo.sh --source /your/local/clone benchmark/repos/myrepo.git
  2. Click New Test → configure paths → run
  3. Watch the live log, then compare the results side by side

What is being measured

naive
git clone --depth=1 → all blobs materialised (actions/checkout@v4 default)
blobless
filter=blob:none → sparse checkout of target paths (one lazy fetch per blob)
agentcache
blobless clone → POST /resolve → ONE batched fetch of exact blobs

All git traffic passes through the counting proxy (port → ). Bytes are attributed per run via snapshot delta.
