What is being measured

naive
git clone --depth=1 → all blobs materialised (actions/checkout@v4 default)
blobless
filter=blob:none → sparse checkout of target paths (one lazy fetch per blob)
agentgitsmart
blobless clone → POST /resolve → ONE batched fetch of exact blobs

How to read this: Every campaign starts by erasing all agent-git-smart artifacts (verified in the log). The cold first pass is a genuinely fresh repo — no symbol/manifest cache and no CDN bundle yet — so agentgitsmart must pull full history over the network, just like blobless (often more, since it fetches unshallowed history). Only once the cache + bundle exist (built by the hook / lazy-gen) do later warm passes become cheap. That cold→warm jump is the whole point.
